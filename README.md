# 回收乐园 ♻️ (Recycle Park for Kids)

给 5 岁 Ada 的垃圾分类 + 经营装饰游戏。可爱厚涂卡通风（参考《潜水员戴夫》配色玩法）。

## 核心玩法闭环（v0.2 重做）
1. **清理海洋**（大海关卡）— 垃圾漂在海里、挡住小鱼游动（小鱼会受惊冒「!」）。**直接把垃圾拖进对的分类箱**：可回收 / 厨余 / 有害 / 其他。拖动时光标变成抄网。
2. **变材料** — 分对的垃圾立刻炼成再生原料，计入顶部计分牌：木材 / 塑料 / 金属 / 玻璃 / 纸 / 橡胶。
3. **随时建造** — 任意场景点「建造乐园」即可打开造物页（可上下滚动/滚轮），每件物品显示需要多少各种原料（够=绿色可造，不够=红色）。共 **25 种**：餐盘/杯子/茶壶、凳/桌/长椅、花盆/花丛/路灯/信箱/小旗/气球/风筝/遮阳伞/野餐篮/石像、小树/喷泉/跷跷板/秋千/滑梯/自行车/帐篷……
4. **原料不够怎么办** — 回大海继续清理，或点「🔄 刷新海域」让新垃圾漂进来再搜。**大海↔造东西↔乐园 三页互相直达**。
5. **装饰乐园**（占位 + 物理大小 + 叠放）
   - 物品按真实相对大小显示（桌子比杯子大），带落影占位。
   - **可重新布置**：拖动已摆好的东西移动。
   - **可单独删除**：拖住它拖到顶部「🗑 删除区」即删除并退回库存。
   - **可叠放**：杯子/茶壶/餐盘能放到桌子、长椅、凳子等台面上。
   - 越漂亮人气越高，依次吸引小猫/小兔/小鸟/小熊/小朋友/小狐狸来玩。

## 怎么玩
- **电脑**：直接双击 `index.html`，或用浏览器打开。
- **iPad（推荐横屏，可添加成 App）**：
  1. 在 Mac 上**双击 `play-on-ipad.command`**（会打开一个黑窗口并显示一个网址，例如 `http://192.168.3.122:8080`）。
  2. iPad 连**同一个 WiFi**，用 **Safari** 打开那个网址。
  3. 点 Safari 的「分享」→「**添加到主屏幕**」，桌面就会出现「回收乐园」App 图标，点开就是**全屏 App**（已处理触控、全屏、禁缩放、横屏提示）。
  - 玩的时候别关 Mac 上的黑窗口；玩完按 Ctrl+C 或直接关掉即可。
  - 想要一个永久网址（不开 Mac 也能玩）需要把它部署到静态托管（如 GitHub Pages / Netlify）。

全程有中文语音引导。

## 技术
- 纯前端，单页 Canvas，无需安装。
- 美术：垃圾图标用 [OpenMoji](https://openmoji.org/)（CC BY-SA 4.0，清晰易识别）；鱼/水母/海洋环境/物品/访客为程序化绘制（`js/sprites.js` + `js/marine.js` 动画引擎）。放 `assets/sprites/<key>.png` 即可覆盖任意贴图。
- 素材署名见 `assets/sprites/ATTRIBUTION.txt`。
- 语音：`edge-tts` 预生成 MP3（温暖女声 Xiaoxiao）。改台词后跑 `python3 gen_voice.py` 重新生成。

## 文件结构
```
index.html              入口
css/style.css           样式
js/data.js              游戏数据：垃圾/材料/配方/物品/关卡/访客
js/sprites.js           程序化美术（支持 PNG 覆盖）
js/audio.js             音效 + 语音
js/engine.js            引擎：画布/主循环/场景管理/输入/存档/特效
js/scenes_collect.js    场景：主菜单 / 大海捡垃圾 / 垃圾分类
js/scenes_build.js      场景：造物 / 装饰乐园
voice_lines.js          语音台词
gen_voice.py            语音生成脚本
audio/                  预生成语音 MP3
assets/sprites/         （可选）AI 生成贴图，按 key 命名覆盖程序绘制
```
