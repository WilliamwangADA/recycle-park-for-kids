# 回收乐园 ♻️ (Recycle Park for Kids)

给 5 岁 Ada 的垃圾分类 + 经营装饰游戏。可爱厚涂卡通风（参考《潜水员戴夫》配色玩法）。

## 核心玩法闭环（v0.2 重做）
1. **清理海洋**（大海关卡）— 垃圾漂在海里、挡住小鱼游动（小鱼会受惊冒「!」）。**直接把垃圾拖进对的分类箱**：可回收 / 厨余 / 有害 / 其他。拖动时光标变成抄网。
2. **变材料** — 分对的垃圾立刻炼成再生原料，计入顶部计分牌：木材 / 塑料 / 金属 / 玻璃 / 纸 / 橡胶。
3. **随时建造** — 任意场景点「建造乐园」即可打开造物页，每件物品显示需要多少各种原料（够=绿色可造，不够=红色）。共 15 种：滑梯、跷跷板、自行车、帐篷、长椅、小树、花丛、路灯……
4. **原料不够怎么办** — 回大海继续清理，或点「🔄 刷新海域」让新垃圾漂进来再搜（也可去别的关卡，后续开放）。
5. **装饰乐园** — 把做好的物品拖到草地上摆放，越漂亮人气越高，吸引小猫、小兔、小熊、小朋友等来玩。

## 怎么玩
直接双击 `index.html`，或用浏览器打开。手机 / iPad / 电脑都能玩，全程有中文语音引导。

## 技术
- 纯前端，单页 Canvas，无需安装。
- 美术：垃圾图标用 [OpenMoji](https://openmoji.org/)（CC BY-SA 4.0，清晰易识别）；鱼/水母/海洋环境/物品/访客为程序化绘制（`js/sprites.js` + `js/marine.js` 动画引擎）。放 `assets/sprites/<key>.png` 即可覆盖任意贴图。
- 素材署名见 `assets/sprites/ATTRIBUTION.txt`。
- 语音：`edge-tts` 预生成 MP3（温暖女声 Xiaoxiao）。改台词后跑 `python3 gen_voice.py` 重新生成。

## 文件结构
```
index.html              入口
css/style.css           样式
js/data.js              游戏数据：垃圾/材料/配方/物品/关卡/访客
js/sprites.js           程序化美术（支持 PNG 覆盖）
js/audio.js             音效 + 语音
js/engine.js            引擎：画布/主循环/场景管理/输入/存档/特效
js/scenes_collect.js    场景：主菜单 / 大海捡垃圾 / 垃圾分类
js/scenes_build.js      场景：造物 / 装饰乐园
voice_lines.js          语音台词
gen_voice.py            语音生成脚本
audio/                  预生成语音 MP3
assets/sprites/         （可选）AI 生成贴图，按 key 命名覆盖程序绘制
```
